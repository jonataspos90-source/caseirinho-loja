# Caseirinho Loja V8.6.0

- Checkout por CEP: rua, bairro, cidade e UF preenchidos via API; cliente informa o número.
- Frete automático pelas regras publicadas do Cadastro de Frete do ERP; sem regra = cotação pendente no ERP.

- Toda foto de produto mostra “Imagem meramente ilustrativa”.
- Consentimento LGPD obrigatório conforme política publicada pelo ERP e acesso à Política de Privacidade.
