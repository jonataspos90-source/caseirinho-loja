# Caseirinho Loja V8.4.4

Quando a forma de pagamento selecionada contém PIX e a Loja recebeu a configuração PIX publicada pelo ERP:

- gera BR Code PIX localmente;
- inclui o valor exato do pedido;
- mostra QR Code e PIX Copia e Cola na confirmação;
- mostra o PIX em Meus Pedidos;
- inclui QR Code PIX na impressão/PDF do pedido.

O QR Code é gerado localmente no navegador, sem serviço externo.
