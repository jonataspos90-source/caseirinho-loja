# Caseirinho — Loja Online

Frontend público do E-commerce Caseirinho.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `caseirinho-loja`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. No GitHub abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Clique em **Save**.
7. Aguarde o GitHub exibir a URL publicada.

## Segurança

Este repositório é somente para o E-commerce público. Não publique aqui o ERP administrativo nem nenhuma chave `ERP_API_KEY`, senha, `DATABASE_URL` ou outro segredo.

A loja usa somente as rotas públicas da API do Caseirinho.
